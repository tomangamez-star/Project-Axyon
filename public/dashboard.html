STEP BY STEP

How to register a group

  1. Add the bot's number to the group. The number is the one you paired on the Pairing screen.
  2. Make the bot a group admin. Group info → Members → tap the bot → Make group admin. This is required for duel admin promotion, and it lets any admin run !register.
  3. Send the command in the group: !register — or !register My Group Name to name it yourself. If you leave the name out, the bot uses the group's own subject.
  4. The bot replies: ⌘ AXYN CORE then ✅ GROUP REGISTERED, the group name, and "Architect will now respond here."
  5. Test it: send !ping. You should get 🎳 Pong — ⌘ AXYN CORE.

Who can run it: AXYON, or any group admin. A normal member gets "🛡️ Only AXYON or a group admin can register a group."

TROUBLESHOOTING

If the bot says the group isn't registered

An unregistered group is silent for ordinary chat by design. But if you send a command in one, the bot now answers once with the registration steps instead of ignoring you.

  1. Send !register in the group. That is the fix in almost every case.
  2. If it says "Only AXYON or a group admin can register a group" — you are a normal member. Ask a group admin to send !register, or send it from the AXYON number.
  3. If it says "Run this inside the group you want to register" — you sent it in a DM. Registration is per group, so it has to be sent inside the group.
  4. If it still stays silent — open the Groups screen here. The group may be paused. Press Resume. If it is not listed at all, the registration never landed: send !register again.
  5. If nothing at all works — check the Overview screen. If the account shows Disconnected, press Reconnect on the Pairing screen.

ASSISTANT

Asking the bot a question

The bot has a helper that knows every command. It explains; it cannot run anything.

  1. @-mention the bot in a group: @Architect how do I play a mode?
  2. Or reply to any message the bot sent and just type your question.
  3. Or use the command: !ai how do ranks work?

It defers to AXYON above everyone, then RHM, then group admins. It will never claim to have reset, granted or changed anything — it tells you which command to type instead.

MEDIA

Playing a song

!play <song or artist> searches a public catalogue, shows the cover art, then sends the audio.

If a full track cannot be fetched, the bot sends the catalogue preview and says so in the caption — it never presents a 30-second clip as the whole song.
