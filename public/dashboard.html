AXYN CORE • GROUP REGISTRATION

Register a group with AXYON

Registration is tied to the WhatsApp group JID, never its display name. Only verified AXYON identities can register, change modes, manage features, suspend, reactivate or remove a group. WhatsApp group-admin status does not grant AXYON authority.

Registration commandWhat it enables
!register group normalOriginal gaming environment: General, Combat, Dungeon, Cards, Social and Economy features enabled by default.
!register group modesOfficial modes registration. Starts with no mode features enabled; AXYON enables each feature individually.
!register group duelDuel-only registration. Other systems remain unavailable.

Run the command inside the target group. Architect records that group's unique JID. The same player's profile remains available in other registered groups, but access is checked separately in each group.

AXYON MANAGEMENT

Control group access

These commands are AXYON-only. Run them inside the group being managed, except !register list, which lists the registry.

  • !register view or !group info — inspect the current registration.
  • !register list — list registered groups.
  • !register mode normal|modes|duel — change the registration mode.
  • !group features — inspect enabled and available features.
  • !group enable combat / !group disable combat — toggle a feature.
  • !group suspend [reason] / !group reactivate — control group status.
  • !group disable / !group enable — disable or restore all group access.
  • !group remove — remove the group from active registration without deleting player accounts.

Feature routing: !fight and !stages belong to Combat; !floor, !dungeon and !party belong to Dungeon; !duel belongs to Duel; card commands belong to Cards. Player game modes no longer control command access. !mode has been removed.

TROUBLESHOOTING

When a command is unavailable

Architect checks group registration status and the feature assigned to the command. A player profile alone does not grant access in an unregistered group.

  1. Access denied: ask an authorized AXYON operator to register the group with !register group normal, modes or duel.
  2. Feature unavailable: AXYON must enable the relevant feature with !group enable <feature>.
  3. Group suspended or disabled: only AXYON can reactivate the group.
  4. Dungeon or Combat command: check that the group has the matching dungeon or combat feature. Player-level !mode switching is no longer used.

ASSISTANT

Asking the bot a question

The bot has a helper that knows every command. It explains; it cannot run anything.

  1. @-mention the bot in a group: @Architect how do I play a mode?
  2. Or reply to any message the bot sent and just type your question.
  3. Or use the command: !ai how do ranks work?

It defers to AXYON above everyone, then RHM, then group admins. It will never claim to have reset, granted or changed anything — it tells you which command to type instead.

MEDIA

Playing a song

!play <song or artist> searches a public catalogue, shows the cover art, then sends the audio.

The audio is the full track, streamed from Audius. If Audius has no match the bot falls back to yt-dlp, and only as a last resort to a catalogue preview — and in that case it says so in the caption. It never presents a 30-second clip as the whole song.
