PROJECT AXYON — UPDATED BUILD

WHAT CHANGED

1) Unified adventure progression
- !explore, !floor and !fight now enter the player's saved next floor.
- Number arguments are ignored; players cannot manually jump to a floor.
- A win advances the one shared floor counter.
- !stages is an optional progress view, not a required battle-selection menu.
- The old separate !boss command has been removed. Guardian encounters occur
  automatically on every fifth floor; later floors scale beyond the original five.
- Missing built-in floor rows are re-seeded idempotently when floors are read.

2) Story and diversion encounters
- Groq-backed AI mission introductions are generated when available, with a
  deterministic in-game fallback so the adventure still works during outages.
- Every third floor introduces a story diversion.
- The Wrath's hailstorm is a combat decision with four contextual choices:
  use an available class ability (or Power Burst), interrupt the blast, fight
  head-on, or trust your instincts.
- Other diversions include rescue, mystery and treasure scenes. These are
  non-combat choices with immediate consequences/rewards and automatic floor
  progression.
- WhatsApp quick-reply buttons are used where supported. !choose 1-4 is the
  text-command fallback.
- !attack, !defend, abilities, healing, cards and retreat remain available in
  ordinary combat. A player can still use !attack instead of tapping options.

3) Player registration and menu
- Repeating !arise now says the player is already risen and points to !menu.
- !menu opens the player profile/status view, including current floor.

4) Architect AI
- Responds to the configured bot name, direct WhatsApp mentions, and replies
  to its own recent messages (including native-flow button messages).
- Reply detection tracks bot-sent message IDs as well as quoted author IDs.
- Personality is confident and playfully egotistical, while remaining respectful.
- AXYON authority is based on configured owner/AXYON numbers, not group-admin
  status.
- Groq is primary; AI_API_URL / AI_API_KEY (or AI_API as URL/key) is the
  OpenAI-compatible fallback; public routes are last resort.

5) Preserved earlier fixes
- Registered-group modes remain independent per group; DM mode remains per player.
- Card-drop captions no longer include artwork/source credits or generation chatter.

COMMANDS
- !arise — register once
- !menu — player status
- !explore — enter the next encounter
- !floor — alias for !explore
- !fight — alias for !explore
- !stages — optional progression view
- !choose 1-4 — resolve a story diversion if buttons are unavailable
- !attack / !defend / !heal / !class / !carduse / !retreat — battle actions
- !battle — resume the current encounter or story choice

CONFIGURATION
- Keep GROQ_API_KEY in the deployment environment.
- GROQ_MODEL defaults to openai/gpt-oss-120b; set it explicitly only if needed.
- Optional fallback: AI_API_URL, AI_API_KEY, AI_API_MODEL.
- AI_API may also be set to an OpenAI-compatible URL or an API key. If it is
  only a key, the default endpoint is https://api.openai.com/v1/chat/completions.

IMPORTANT SECURITY NOTE
The uploaded source archive contains data/cookies.txt with browser/session
cookies, including authentication tokens. This build intentionally omits that
file from the distributable archives and adds it to .gitignore. Before pushing,
remove it from Git tracking with:
  git rm --cached data/cookies.txt
Then revoke/rotate the affected session tokens with their providers. Adding a
.gitignore entry does not untrack a file that Git already tracks.
